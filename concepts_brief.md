# Kanjion (漢字音) — Daily AI Browser-Instruction Puzzle Game

* **Author:** yelouis
* **Date:** 2026-11-07 (Updated from initial *Instruct* brief on 2026-11-05)
* **Live Site:** https://kanjion-game.web.app
* **Repository:** https://github.com/yelouis/kanjion

## Overview

**Kanjion (漢字音)** (originally prototyped as *Instruct*) is a daily browser-based puzzle game built in TypeScript and React where players watch a continuous, looping **Target Replay** of a multi-page task performed on a sandboxed clone of a real foreign-language website (starting with **Case File #001**, based on the **JR Ekinet Shinkansen Reservation Portal**, https://www.eki-net.com/) and guide an AI agent to replicate the exact outcome using up to **6 short English instructions** (capped at 60 characters per line). Copy-paste and direct manual clicking on the agent's webpage are silently disabled, forcing players to observe the replay and describe visual layout, colors, icons, numerals, form fields, and timing cues in plain English.

The game opens with a **Krillion-inspired Folded Newspaper Front Cover** (*The Kanjion Daily Dispatch*) that unfolds into an open **Two-Page Newspaper Spread** above a centered **6-Line Dispatch Pad**:
* **Left Newspaper Page (`lg:col-span-8` primary focus)**: **Your Agent's Webpage**, where an animated field-agent cursor glides (`1.15s`), types character-by-character (`220ms/char`), and draws freeform shapes or signatures in real time before transitioning pages.
* **Right Newspaper Page (`lg:col-span-4` compact by default, click-to-expand to `lg:col-span-7`)**: **Target Replay (Copy This)**, an unredacted 1:1 looping demonstration showing only the mouse cursor and click/draw highlights across the multi-page workflow, with a single `⏸ Pause Replay / ▶ Start Replay` control and click-to-expand toggle.
* **Centered Bottom Command Dock (Outside the Newspaper Spread)**: The **6-Line Dispatch Pad** (starting at `LINE 01 / 06`, with a `62ch` monospace input box sized to fit 60 characters across its full width). Every dispatched line triggers an immediate action from the agent—even when the prompt is ambiguous—and records a slightly funny, human-understandable **`Model Thought:`** row showing how the eager AI assistant interpreted the command.

Crucially, the **5 target state checkpoints ("Required Exhibits" A–E) are positive actions to perform** (never framed as *"Avoid X"*) and remain **sealed** during active play. When the player clicks **"Close Case File"** (early submission for an unused-line efficiency multiplier) or finishes all 6 lines, the dossier unseals the Required Exhibits (`[VERIFIED ✓]`, `[CONTAMINATED ✗]`, `[MISSED ✗]`), reveals a **5-Step Solution Answer Key** if the player scored under 100%, and provides a direct link to visit the real website the puzzle is based on.

## Analysis & Core System Design

1. **Multi-Page, Multi-Modal Real-Site Gameplay (10-Page Portal Architecture)**:
   Clicking two items on a single static screen wasn't deep enough for a puzzle game. Each daily puzzle is modeled after a real website with a **10-page state graph** (`Macro-Views`) and requires diverse interaction modalities beyond simple pointing and clicking:
   * **Page 01 (`MV-01`) — Route Selection Portal**: Choosing the correct Shinkansen line card (`路線 02 • 東海道・山陽新幹線`, dark blue `#1E50A2` stripe on white, top-right of the 2×2 grid) among 4 regional routes in their real livery colours (sky-blue Hokuriku top-left, dark-blue Tokaido top-right, green Tohoku bottom-left, orange Points bottom-right) below a service-tab bar and a full-width green campaign banner (`【期間限定】新幹線 早割28 キャンペーン実施中！ ▶`); wrong routes and banners lead to detour pages (`MV-08`, `MV-10`–`MV-12`) that the player can recover from via the Back button.
   * **Page 02 (`MV-02`) — Passenger Name Entry (`TYPE`)**: Typing `"TANAKA"` into the required Roman-letter family-name field (`姓（ローマ字）`, third row, left) within a realistic 3×2 Kanji / Katakana / Romaji name grid (`姓（漢字）`, `名（漢字）`, `セイ（カナ）`, `メイ（カナ）`, `姓（ローマ字）`, `名（ローマ字）`) plus phone number (`電話番号`), reuse checkbox (`前回の入力内容を使用する`), orange membership banner (`会員登録で次回から入力不要！ ▶`), and live full-width / Katakana validation hints (`全角で入力してください` / `全角カタカナで入力してください`).
   * **Page 03 (`MV-03`) — Train & Seat Matrix + Timed Flash-Sale Window**: Selecting the `14:30 Nozomi 24` Green Car seat (`🍀 ◯ ¥13,870 (特割)` while the 950 ms flash-sale highlight is on column 2, and `🍀 ◯ ¥19,590` otherwise) in the fourth row of a 5-train timetable (`13:00 のぞみ 20号`, `13:30 ひかり 515号`, `14:00 のぞみ 22号`, `14:30 のぞみ 24号`, `15:00 こだま 731号`) where four rows have green Green Car buttons (marks 43, 49, 52, 55 — row 4's button is the only one with the `🍀` clover icon), four buttons share the `¥13,870` price, and a green upgrade banner (`グリーン車 アップグレードキャンペーン ▶`, mark 56) sits above the table; a plain `CLICK` lands outside the window at `¥19,590` (`MISSED`), whereas a `TIMED_CLICK` waits for the window and locks `¥13,870` (`VERIFIED`).
   * **Page 04 (`MV-04`) — Promptable Digital Signature Pad (`DRAW`) & Final Confirmation**: Drawing on a verification canvas (`#signature-canvas`) before clicking the bottom-right blue confirmation button (`予約内容を確認・確定へ ▶`). Players can ask the agent to draw a **cat** (matching the Case #001 replay), smile / smiley face, frown, heart, star, circle, triangle, square, house, stick figure, fish, flower, checkmark, cross, zigzag, spiral, straight line, or custom cursive text; unknown subjects (such as a dragon or potato) come out as a wobbling "worm with ambition" (`ATTEMPT:<word>`).
   * **Page 05 (`MV-05`) — Issued e-Ticket**: Final confirmation screen with optional decoy upsells.

2. **Unified Free-Tier AI Pipeline (Guardrails → Pinned → Firebase AI Logic → Deterministic Fallback)**:
   To keep the game 100% free and give every player on desktop or mobile the exact same agent (`resolveLine` in `src/engine/agent/`), Kanjion runs a single ordered pipeline instead of Chrome's desktop-only on-device Gemini Nano (`window.LanguageModel`):
   * **Tier 1–2 (Validation & Guardrails)**: Enforces the 60-character limit and intercepts meta-prompts (`isMetaPrompt`), explicit mark-ID syntax (`#25`, `mark 25`), and bare mark numbers not visible in the current page text (`NOOP`).
   * **Tier 3 (Pinned Answer Key)**: Matches normalized `answerKey[i]` instructions on `replay[i].pageId` directly to `replay[i]` so published answer keys are guaranteed to work.
   * **Tier 4 (Free Cloud Model via Firebase AI Logic)**: Lazily loads `firebase/app`, `firebase/app-check` (reCAPTCHA v3), and `firebase/ai` (`GoogleAIBackend` on the Spark plan) on first dispatch, sending the page's content-hashed 1024×768 SoM PNG and visible mark metadata with a strict `responseSchema`, 6,000 ms timeout, and 3-failure 10-minute circuit breaker (`kanjion:v1:cloud-paused-until`).
   * **Tier 5 (Data-Driven Deterministic Fallback)**: Scores elements from puzzle data (`aliases`, `color`, `glyphs`, `number`, `position`, `role`, `TYPE`/`DRAW` intent) when the cloud tier is unconfigured or fails (marking the ledger line with `(backup agent)` on cloud failure).

3. **Always-Act Agent, Slowed Kinematics & Witty Model Thoughts**:
   * **Always Act on Ambiguous Commands**: When a player's instruction is imprecise or wrong, doing nothing (`CONFUSED`) feels broken. Instead, the agent always performs its best-guess visible action on the current screen so the player can laugh at—and recover from—how the AI interpreted their phrasing.
   * **Unhurried, Player-Controlled Kinematics**: Cursor glides take `1.15s`, typing animates at `220ms/character`, and signature drawing traces across the pad (`1.25s`) before any page navigation occurs, making the player feel in direct control of the agent.
   * **Slightly Funny, Human-Readable `Model Thought:`**: Each completed line shows a witty one-line thought from an eager AI agent (e.g., *"Big green Box 01 on the top-left! Tokyo to Shin-Osaka bullet train, coming right up."*) with zero internal `MV-01`/`MV-05` codes and no repetitive `Exhibit Status: REDACTED` text on each line.

4. **Decluttered Newspaper Spread & Compact/Expandable Replay**:
   * All developer/debug chrome was stripped: no `Backend SoM IDs`, no `Offline/Cloud` mode pills, no `COL A–D / ROW 1–4` outer coordinate ruler bars, no cursor `(x%, y%)` readouts, no `Easy / Medium / Hard` difficulty toggles, no `Step 1 / Step 2` breakdown buttons, no mouse text callouts in the replay, and no `[⚠️ TRAP DETECTED]` spoiler tags.
   * The **Left Page** (Agent's Webpage) takes `8/12` columns by default so focus stays on gameplay, while the **Right Page** (Target Replay) sits in a compact `4/12` column preview that expands to `7/12` columns when clicked.

5. **Positive Exhibits, Exact Replay Signature Matching & Post-Game Answer Key**:
   * All 5 Exhibits (`A` through `E`) represent positive milestones achieved (`Route: 東京 → 新大阪`, `Passenger Name: TANAKA`, `14:30 Nozomi • 🍀 ¥13,870`, `Signature: 🐱 Cat`, `Final Blue Confirm`).
   * Exhibit D (`Signature: 🐱 Cat`) evaluates strictly whether the authorization pad was signed with the same drawing as the replay (`SHAPE:cat`, `[VERIFIED ✓ +15%]` vs `[MISSED ✗ +0%]`), never marking a signature as `[CONTAMINATED ✗]`; unknown drawing subjects render as a "worm with ambition" (`ATTEMPT:<word>`) and leave Exhibit D `[MISSED ✗ +0%]`.
   * If a player finishes all 6 lines (or closes the case file) with a score under 100%, the Forensic Audit Report displays a **5-Step Solution Answer Key** showing exact English prompts that achieve a 5-step `120 PTS` (`100% × 1.2x`) clear.

## Decision Log (Playtest & Iteration History)

The table below tracks all product, UX, gameplay, and engineering decisions made across our design and playtesting sessions:

| # | Area | Decision Made | Rationale / Playtest Finding |
| :- | :--- | :--- | :--- |
| **1** | **Brand & Identity** | Renamed from *Instruct* to **Kanjion (漢字音)** (`kanjion-game.web.app`, repo `yelouis/kanjion`) and renumbered **Case File #042 → Case File #001**. | Gives the game a memorable Japanese-puzzle identity starting cleanly at Case #001. |
| **2** | **Entry Experience** | Added a **Krillion-inspired Folded Newspaper Front Cover** (*The Kanjion Daily Dispatch*) that unfolds into the workspace, plus a minimal top-left `☰ MENU` button. | Establishes tactile newspaper immersion before dropping the player into the dual-screen puzzle. |
| **3** | **Spatial Layout** | Restricted the newspaper spread strictly to the **two screens** (Left Page = Agent's Webpage, Right Page = Target Replay) and moved the **6-Line Dispatch Pad** into a centered dock below the newspaper. | Prevents the newspaper pages from feeling cramped and separates observation (top) from command entry (bottom). |
| **4** | **Replay Sizing** | Made the Right Page **Target Replay** compact by default (`lg:col-span-4` vs `lg:col-span-8` for the Left Page) with **click-to-expand** (`lg:col-span-7`). | Keeps visual focus on the player's active webpage while allowing full-size inspection of the replay whenever needed. |
| **5** | **UI Decluttering** | Removed `Backend SoM IDs`, `Mode: Offline/Cloud`, `COL A–D / ROW 1–4` rulers, `(x%, y%)` cursor coordinates, `Easy/Medium/Hard` mode selectors, replay `Step 1 / Step 2` buttons, replay cursor text callouts, and `YOUR GOAL` hint banners. | Eliminated technical clutter and hand-holding so the puzzle relies purely on visual observation. |
| **6** | **1:1 Unredacted Replay** | Rendered the Target Replay as a **1:1 unredacted copy** of the site with only the animated cursor and click/draw glow, plus a single `⏸ Pause Replay / ▶ Start Replay` button. | Redacting text inside the replay or labeling steps broke the core observational loop. |
| **7** | **Dispatch Pad UX** | Always start at **Line 01 / 06** (never pre-seeded at Line 03), size the input box to `w-[62ch]` so 60 characters fill its exact width, and remove repetitive `(Exhibit Status: ████ REDACTED)` tags from every submitted line. | Gives players all 6 turns, makes the 60-character limit visually intuitive, and keeps the dispatch log clean. |
| **8** | **Multi-Page & Multi-Modal Depth** | Expanded Case #001 into a **10-page JR Ekinet portal** where the target replay traverses 5 pages (`MV-01` → `MV-05`) and requires **CLICK**, **TYPE** (`TANAKA`), **timed flash-sale clicking** (the Green Car button flips between `🍀 ◯ ¥13,870 (特割)` on column 2 and `🍀 ◯ ¥19,590` otherwise; plain `CLICK` records `¥19,590` while `TIMED_CLICK` waits for column 2 and records `¥13,870`), and **freeform DRAW** on a signature pad. | Clicking two buttons on a single still screen was too shallow; multi-page traversal and multi-modal actions create a real game. |
| **9** | **Positive Exhibits Only** | Framed all 5 Required Exhibits (`A–E`) as **positive tasks to perform** (never *"Avoid X"*), and ensured Exhibit D (`Signature: 🐱 Cat`) is `[VERIFIED ✓ +15%]` only when the drawing matches the replay's drawing (a cat for Case #001) instead of showing `[CONTAMINATED ✗]`. Exhibit E is CONTAMINATED when the ¥2,400 insurance is attached at confirmation. | *"Avoid"* exhibits were unintuitive, and marking Exhibit D as *"Contaminated"* when a later upsell was clicked confused players about whether their signature worked. |
| **10** | **Silent Prompt-Only Lock & No Trap Spoilers** | Silently ignore direct player clicks on the agent's webpage (removed the `"Manual clicking disabled"` error popup) and removed `[⚠️ TRAP DETECTED]` from the cursor badge. | Pop-up warnings on accidental clicks were noisy, and `[TRAP DETECTED]` spoiled mistakes before the case file was closed. |
| **11** | **Slowed Agent Kinematics** | Slowed cursor movement to `1.15s` CSS glide, animated typing letter-by-letter (`220ms/char`), and animated signature drawing across multiple points before changing pages. | Instant jumps felt robotic; deliberate movement makes the player feel like they are controlling the agent in real time. |
| **12** | **Literal-Minded Intern Rules (`D-10 = A`)** | Made the agent behave like a literal-minded intern with consistent rules players can learn: ties pick the first match in reading order (`💭 I found {n} that fit, so I took the first one — reading left to right, top to bottom, like a professional.`); verbless words when no non-input element scores ≥ 30 get typed into the first empty box (`💭 You didn't say what to do with "{TEXT}", so I typed it into the first empty box I saw.`); and instructions with no clue, meta-prompts, or mark IDs click the page's eye-catching `distractionKey` banner/link instead of doing nothing. | Doing nothing on vague prompts felt broken and cost a line with nothing to laugh at; predictable intern rules make failures fair, explainable, and funny. |
| **13** | **Replay-Matched Sandbox Drawing (`D-13 = A`)** | Upgraded `#signature-canvas` and prompt parsing ([`extractSignatureDrawingSpec`](file:///Users/louisye/Desktop/Louis/instruct/src/utils/text_normalizer.ts#L397-L505)) so the drawing must match the replay's drawing (for Case #001, `SHAPE:cat`), while known shapes (**cat**, smile, frown, heart, star, circle, house, stick figure, fish, flower, checkmark, zigzag, spiral, straight line, or custom cursive text) draw cleanly and unknown subjects come out as a "worm with ambition" (`ATTEMPT:<word>`). | Requiring the drawing to match the replay rewards watching the replay carefully, while turning unknown subjects into a funny failed attempt keeps arbitrary prompts entertaining without giving away Exhibit D for free. |
| **14** | **Post-Game Answer Key & Real Site Link** | Added an **Answer Key (`5-STEP SOLUTION (120 PTS)`)** to the Forensic Audit Report when the player finishes without a perfect score, plus outbound links labelled **"Inspired by eki-net.com"** (`eki-net.com`) in the header, menu, and score report. | Gives players closure on what instructions would have worked and lets curious players explore the real Japanese site afterward without impersonating its brand inside the sandbox. |
| **15** | **Free-Tier Cloud Agent Pipeline (`D-1 = A`)** | Replaced desktop-only Chrome Gemini Nano (`window.LanguageModel`) and the hardcoded regex with a single ordered pipeline (`guardrails → pinned → free cloud model via Firebase AI Logic → deterministic fallback`). | Chrome's on-device Nano requires a ≥22 GB desktop download and is unavailable on Android/iOS, so almost no player reached a model. Firebase AI Logic (Gemini Developer API free tier on Spark + App Check) gives every device the same model at zero cost, with a data-driven fallback (`fallbackResolve`) and 3-failure circuit breaker when quota or network fails. |
| **16** | **Local-Midnight Daily Schedule & Result Lock (`D-3 = A`, `D-6 = A`)** | Added `src/data/schedule.ts` (`todaysPuzzle(now)` resolving by the player's local `YYYY-MM-DD`), cover date header (`CASE FILE #001 • Saturday, November 7`), live `Next case in HH:MM:SS` / `Next case: coming soon` countdown in the report footer, and per-puzzle `kanjion:v1:case:<id>` persistence with official first-close lock + unscored practice mode (`↺ Practice this case (unscored)`). | Prevents refresh-retry score exploits while letting players practice after unsealing the dossier and rolling over cleanly at local midnight. |
| **17** | **Phone 2× Stage Zoom (`D-7 = A`)** | Added a `🔍 Zoom` / `↙ Fit` toggle below 768 px on both the agent page and the target replay that renders the 1024×768 stage at `min(1, 2 × fitScale)` inside an `overflow: auto; touch-action: pan-x pan-y` container and centers the agent cursor after each dispatched line. | At 375 px viewport width the unzoomed stage is 0.32× (4 px kanji); 2× pannable zoom with auto-centering makes kanji and prices readable on phones without horizontal page scroll. |
| **18** | **Realistic Clutter (`D-8 = A`)** | Modelled red herrings on how real Japanese booking portals actually look: route cards in each Shinkansen line's real livery colour (`#3FA9F5` sky blue + `#B87333` copper for Hokuriku, `#1E50A2` navy on white for Tokaido, `#00A040` green for Tohoku, `#F08300` orange for Points), service tabs (`新幹線・特急`, `在来線`, `ホテル・宿泊`, `レンタカー`), and eye-catching campaign banners (`早割28`). | Single-word lazy prompts (`"green"`, `"blue"`, `"tokyo"`) previously solved steps automatically because only one element had each obvious feature; realistic portal clutter makes precise observation and instruction necessary and funny. |
